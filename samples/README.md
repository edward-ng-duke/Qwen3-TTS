# TTS 复现性 / 一致性 诊断样本

服务：`POST http://10.0.0.94:4967/v1/tts`（customvoice 变体，speaker=vivian，language=Chinese）
日期：2026-06-17

各文件夹分别对应一个结论。**带着结论去听，对比着听。**

- `00_克隆参考音色库/` —— base 克隆可直接用的 9 条参考音色 + 文字稿（见该目录 README）
- `01`~`04` —— seed / 随机 / 温度 的诊断对照
- `05_voiceclone_同一个人_推荐/` ⭐ —— 你要的"同一个人说不同句子"
- `06_克隆示例_uncle_fu老年男声/` —— 换个参考就是另一个人（老年男声）

---

## 01_同seed可复现_两两完全一样
- 文本：「你好，我是你的语音助手。」
- 每对都是**完全相同的请求连发两次**（固定 `seed=2024`）。
  - `temp0.5_第1/2次`：`sampling.temperature=0.5`，两条 md5 相同（`b52fa66…`）
  - `默认temp0.9_第1/2次`：不带 sampling（走默认 temp=0.9），两条 md5 相同（`3da05cc…`）
- **结论：固定 seed → 字节完全一致、听不出差别。seed 是可复现的，服务端没 bug。**

## 02_无seed每次随机
- 文本：「你好，我是你的语音助手。」，**不带 seed**，完全相同的请求发两次。
- 两条时长都不同（2.24s vs 3.44s），明显两段不同语音。
- **结论：不发 seed = 每次纯随机。这是"每次生成都不一样"的最大来源。**

## 03_换seed换声音_其余全同
- 文本：「你好，我是你的语音助手。」，`temp=0.5`，只改 `seed`（42 / 777 / 2024）。
- 三条音色/语气/时长都不同。
- **结论：换 seed = 换一段声音。你扫过一堆 seed，自然条条不同。**

## 04_温度对比_整批是否像同一人
- 三句**不同文本**，同 `speaker=vivian`、同 `seed=2024`、`top_p=0.8`：
  - `A_temp0.9_*`：高温（默认）
  - `B_temp0.6_*`：低温
- 客观指标（MFCC 音色指纹 + 基频）：
  - 两组的**音色指纹距离都极小**（A=0.0058 / B=0.0066）→ 核心音色其实一直很稳，vivian 没"换人"。
  - 降温**没有**让一致性变好（B 的基频离散反而更大）。
- **结论：「整批像同一个人」靠的不是 temperature。核心音色已经稳，漂的是语调/音高/节奏（很大一部分是不同句子的自然语调）。**
  真要更强的音色锁定 → 走 voice clone（base 变体）+ 固定参考音频。

## 05_voiceclone_同一个人_推荐 ⭐（这就是你要的）
- 服务：本机起的 **base 变体**（`127.0.0.1:4970`），`POST /v1/clone`，ICL 模式（带 ref_text）。
- 做法：拿一条干净的 vivian 片段 `_参考音频_今天天气晴朗.wav` 当**固定参考音频**，
  把 6 句**不同文本**全部克隆到这条音色上，`seed=2024`。
- 客观指标（n=6，句子更多）：**组内音色距离 0.0017**，比 customvoice（0.0058/0.0066）**紧 3~4 倍**；
  基频自然起伏还在（陈述/疑问语调本就不同）。
- **结论：始终是同一个人，自然地说不同的句子。这是满足你需求的正确方案。**
  想换成"你自己的声音"，把参考音频换成你的一段录音 + 对应文字即可。

## 一句话总览
| 想要 | 怎么做 |
|---|---|
| 同输入可复现 | 固定同一个 `seed`（已验证有效） |
| 别每次乱变 | **务必带 seed**（不带就是每次随机） |
| 整批像同一个人 | **voice clone + 固定参考音频**（见 05 文件夹，已验证最优）；temperature 不是杠杆 |

> ⚠️ 另注意：`temperature` 过低（如 0.3）在某些句子上会触发退化生成卡死，且因服务端全局生成锁会**冻住整个 /v1/tts 接口**——别用太低的温度。
